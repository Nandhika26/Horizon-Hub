HORIZON HUB v94 - WEEKEND COMBINED

Perubahan:
- Tampilan jadwal mingguan tidak lagi menampilkan kartu Sabtu kosong secara terpisah.
- Jika Sabtu tidak memiliki mata kuliah, Sabtu dan Minggu digabung dalam satu kartu "Sabtu – Minggu".
- Jika admin menambahkan jadwal kuliah pada Sabtu, jadwal Sabtu tetap ditampilkan sendiri agar informasinya tidak hilang; Minggu tetap ditandai sebagai hari tanpa jadwal.
- Hari kerja tetap ditampilkan seperti sebelumnya.

Pemeriksaan:
- script.js lolos pemeriksaan sintaks Node.js.
- Belum dilakukan uji visual langsung di browser.
