HORIZON HUB v51 — PROFILE TABS & CAMPUS IDENTITY

Basis: Horizon_Hub_v50_Student_Dashboard_Refresh.zip

Pembaruan:
- Halaman Profil Saya disusun menjadi tiga tab: Profil, Keamanan, dan Preferensi.
- Foto gedung kampus menggunakan aset asli assets/kampus.jpg sebagai banner profil.
- Identitas akun ditampilkan pada dropdown ikon profil di header.
- Dropdown menyediakan Profil Saya, Pengaturan Akun, Bantuan, dan Keluar.
- Foto dan nama mahasiswa juga ditampilkan pada shortcut profil di bagian bawah sidebar.
- Tab Profil memuat data akademik read-only, personalisasi nama panggilan, dan unggah/reset foto.
- Tab Keamanan menyediakan perubahan password untuk prototipe lokal.
- Tab Preferensi menyediakan pengaturan kategori notifikasi yang disimpan pada akun lokal.
- Desain login dan fitur lain dari v50 dipertahankan.

Catatan:
- Foto, nickname, password demo, dan preferensi tersimpan di localStorage browser/perangkat.
- Perubahan password pada prototipe ini bukan sistem keamanan produksi. Untuk penggunaan nyata dibutuhkan backend, autentikasi aman, dan database.
- Foto kampus di banner diambil dari file aset asli assets/kampus.jpg.

Cara membuka:
1. Ekstrak ZIP.
2. Buka folder Horizon_Hub_Elza_Account.
3. Buka index.html melalui Preview/Browser (jangan jalankan script.js secara langsung).
