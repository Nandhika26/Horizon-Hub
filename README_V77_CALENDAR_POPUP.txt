HORIZON HUB v77 — ACADEMIC CALENDAR POPUP

Pembaruan dari v76:
- Klik tanggal kalender membuka popup detail agenda (bottom sheet di mobile, modal di desktop).
- Popup memiliki tombol tutup, backdrop blur, dukungan klik backdrop dan tombol Escape.
- Agenda tidak lagi ditampilkan sebagai daftar panjang di bawah kalender.
- Grid kalender dirapikan untuk layar mobile.
- Admin dapat menghapus agenda langsung dari popup.

Catatan: data agenda tetap menggunakan penyimpanan localStorage pada perangkat/browser. Belum tersinkronisasi ke Supabase.
