HORIZON HUB v75 — ACADEMIC CALENDAR MONTH GRID

Perubahan dari v74:
- Tampilan kalender akademik mahasiswa diubah menjadi grid kalender bulanan (Senin–Minggu).
- Tampilan kalender admin juga menggunakan grid kalender bulanan.
- Tanggal dengan agenda diberi penanda titik dan jumlah agenda.
- Pengguna dapat memilih tanggal untuk melihat detail agenda pada tanggal tersebut.
- Navigasi bulan sebelumnya/berikutnya dibatasi pada Juli 2026–Juni 2027.
- Admin tetap dapat menambahkan agenda melalui form dan menghapus agenda dari detail tanggal terpilih.

Data agenda tetap menggunakan seed SY 2026/2027 dari dokumen yang diberikan.
Penyimpanan perubahan masih menggunakan localStorage browser/perangkat, belum tersinkronisasi ke Supabase.

Validasi: JavaScript telah lolos pemeriksaan sintaks (node --check). Belum dilakukan pengujian interaksi end-to-end di browser/hosting.
