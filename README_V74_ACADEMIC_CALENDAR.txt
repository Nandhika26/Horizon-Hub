HORIZON HUB v74 — ACADEMIC CALENDAR

Penambahan:
- Menu Kalender Akademik pada akun mahasiswa.
- Menu Kelola Kalender Akademik pada akun admin (akses terpisah).
- Data awal agenda SY 2026/2027 disusun dari PDF Academic Calendar SY 26/27 yang diberikan.
- Admin dapat menambahkan agenda dan menghapus agenda pada prototype.
- Mahasiswa dapat memilih bulan dan melihat agenda pada bulan tersebut.
- Data perubahan tersimpan di localStorage browser/perangkat; belum sinkron ke Supabase/database atau antarperangkat.

Cara mencoba:
1. Buka index.html melalui hosting/preview seperti biasa.
2. Login sebagai mahasiswa demo, buka menu Kalender Akademik.
3. Logout, login sebagai admin, buka Kelola Kalender Akademik.
4. Tambah atau hapus agenda untuk melihat perubahan pada browser yang sama.

Catatan:
- Data kalender adalah seed awal berdasarkan kalender akademik SY 2026/2027.
- Periksa kembali tanggal dan perubahan resmi kampus sebelum digunakan sebagai pengumuman resmi.
- Fitur ini masih prototype front-end dan tidak mengubah database Supabase.
