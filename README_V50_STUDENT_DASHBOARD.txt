HORIZON HUB v50 — STUDENT DASHBOARD REFINEMENT

Perubahan:
- Homepage mahasiswa disusun ulang dengan alur yang lebih fokus dan lega.
- Ringkasan aktivitas dibuat horizontal dan responsif.
- Student Planner menampilkan tugas aktif dan progress penyelesaian.
- Today's Class menampilkan jadwal berdasarkan hari saat ini dari data jadwal yang tersedia.
- Ringkasan peminjaman menampilkan status Menunggu, Disetujui, dan Ditolak.
- Pengumuman terbaru ditampilkan sebagai daftar yang ringkas.
- Explore Campus menyediakan pintasan ke denah, direktori ruangan, peminjaman fasilitas, dan direktori dosen/staf.
- Lonceng notifikasi ditambahkan pada header dengan panel dropdown, indikator belum dibaca, dan aksi tandai dibaca.
- Desain login dan halaman admin dipertahankan dari paket dasar.

Catatan prototipe:
- Data akun, tugas, pengajuan, pengumuman, dan status notifikasi disimpan pada localStorage browser.
- Notifikasi bersifat lokal pada browser/perangkat yang digunakan; belum tersinkron antarperangkat atau real-time.
- Isi pengumuman contoh tetap diberi konteks sebagai informasi contoh sampai admin menerbitkan pengumuman resmi.

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka folder Horizon_Hub_Elza_Account.
3. Buka index.html melalui Preview/browser (jangan menjalankan script.js secara langsung).
4. Untuk akun demo, gunakan username mahasiswa dan password mhs123.
