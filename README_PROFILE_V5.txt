HORIZON HUB - PROFILE SETTINGS V5

Pembaruan:
- Mahasiswa dan administrator dapat membuka Pengaturan Profil melalui foto/avatar di header.
- Pengguna dapat memilih foto dari galeri/perangkat, melihat pratinjau, menyimpan, atau reset foto.
- Pengguna dapat mengisi nickname dan memilih nama tampilan: nickname atau nama lengkap.
- Foto diperkecil otomatis (maksimal sisi 480px) dan dikompres ke JPEG sebelum disimpan.
- Profil disimpan per akun menggunakan localStorage pada browser/perangkat ini.

Cara mencoba:
1. Ekstrak ZIP.
2. Buka folder Horizon_Hub_Elza_Account.
3. Buka index.html melalui preview/editor atau deploy folder ini.
4. Login sebagai mahasiswa atau admin.
5. Tekan avatar di kanan atas untuk membuka Pengaturan Profil.
6. Pilih foto, isi nickname, pilih mode nama, lalu tekan Simpan Perubahan.

Catatan:
- Foto/nickname belum tersinkron antarperangkat. Perlu backend/database dan storage online untuk sinkronisasi.
- Sistem login masih prototipe frontend, bukan autentikasi produksi.
